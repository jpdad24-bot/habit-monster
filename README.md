# 세 가지 습관 (아이폰 홈 화면 앱)

## 올리기 (GitHub Pages)
1. GitHub에서 새 저장소 만들기 (예: `habit-monster`, Public)
2. 이 폴더의 파일을 전부 올리기: index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png
3. 저장소 Settings → Pages → Branch를 `main` / `(root)`로 저장
4. 1~2분 뒤 `https://<내아이디>.github.io/habit-monster/` 주소가 생김

## 아이폰에 설치
1. Safari로 위 주소 열기
2. 공유 버튼 → "홈 화면에 추가"
3. 홈 화면의 알 아이콘을 누르면 전체 화면 앱으로 열림

## 알아둘 것
- 기록은 아이폰 안에 저장돼요. 앱을 지우면 기록도 같이 지워져요.
- 한 번 열고 나면 인터넷이 없어도 열려요.
- 고친 버전을 올리면 앱을 다음에 열 때 자동으로 새 버전이 돼요.
